# 设计方案

## 问题概述

本项目解决 ModelNet40 三维点云分类任务。ModelNet40 包含 40 类常见物体的 CAD 模型，共计 9843 个训练样本和 2468 个测试样本。每个样本是以 OFF 格式存储的三维点云，包含顶点的 (x, y, z) 坐标及法向量 (nx, ny, nz)。任务目标是对每个点云预测其所属物体类别。

## 数据预处理

原始点云包含数量不等的顶点（通常数百至数千个），需统一采样至固定点数 1024。本项目实现了纯 PyTorch 版本的 Farthest Point Sampling（FPS）算法：从随机初始点出发，迭代选择距离已选点集最远的点，保证采样点在三维空间均匀覆盖。采样后对点云进行归一化处理：先平移到原点（减去所有点的质心），再缩放至单位球（除以最大 L2 距离）。训练时采用数据增强策略：随机 SO(3) 旋转、各向异性缩放（0.8-1.25）和高斯扰动（σ=0.01），提升模型对旋转和尺度变化的鲁棒性。

## 模型设计

项目实现两种代表性点云分类模型：

**DGCNN（动态图卷积网络）**：核心为 EdgeConv 操作。每层首先在特征空间中构建 k=20 近邻的动态图，然后对每条边计算边缘特征 [中心点坐标, 邻居点坐标-中心点坐标]，经过共享 MLP 后取最大值池化。四层 EdgeConv 逐步增加通道数（64→64→128→256），拼接各层输出保留多尺度信息。全局特征通过最大池化和平均池化双重聚合，最后通过三层全连接网络分类。

**PointMLP（残差 MLP 框架）**：采用四阶段层次化设计，每阶段包含局部分组（FPS + kNN）、几何仿射变换和残差 MLP。几何仿射通过可学习的 α 和 β 参数将三维坐标信息注入特征空间：f' = tanh(α) ⊙ f + tanh(β)。Elite 变体使用更宽通道 [128, 256, 512, 1024] 以提升精度，Standard 变体使用较窄通道 [64, 128, 256, 512] 以降低计算量。

## 训练策略

- **优化器**：DGCNN 使用 Adam（lr=0.001），PointMLP 使用 AdamW（lr=0.001），均配合余弦退火学习率调度
- **标签平滑**：使用 label_smoothing=0.2 防止模型过拟合和过度自信
- **训练轮数**：DGCNN 训练 250 轮，PointMLP 训练 300 轮
- **多 GPU**：通过 DataParallel 支持多 GPU 并行训练

## 推理策略

采用多视角投票（Voting）策略提升预测准确率。对每个测试点云生成 num_votes=10 个不同随机 SO(3) 旋转副本，分别输入模型得到 logits，对所有投票的 logits 取平均后取 argmax 得到最终类别。该策略利用了点云分类的旋转不变性假设，通常可带来 1-2 个百分点的精度提升。

## 预期性能

在 ModelNet40 测试集上，DGCNN 预期整体准确率约 92-93%，平均类别准确率约 90-91%；PointMLP (Elite) 预期整体准确率约 93-94%，平均类别准确率约 91-92%。两个模型均能在单个 NVIDIA GPU 上训练，DGCNN 训练约需 2-3 小时，PointMLP 约需 4-5 小时。
